# Welcome to the UWB Localization Mesh Project

This project develops a UWB (Ultra-Wideband)-based middleware that bridges raw radio-frequency ranging data to a usable, high-resolution spatial grid. The middleware fuses data from multiple distributed anchors to determine a user's live position.

This website provides a comprehensive overview of the project, from its impact and system architecture to the algorithms used and the applications developed.
