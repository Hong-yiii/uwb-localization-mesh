## Final Report

The complete final report for the UWB Localization Mesh project is available below:

### [Download Final Report PDF](https://raw.githubusercontent.com/Hong-yiii/uwb-localization-mesh/gh-pages/docs/assets/IS313%20Final_report.pdf)

This comprehensive report covers the entire project lifecycle, including:

- Project objectives and requirements
- System architecture and design decisions
- Implementation details and technical challenges
- Performance analysis and optimization results
- Application development and demonstrations
- Future work and recommendations

The report provides detailed documentation of the middleware development process, from initial concept through to final implementation and validation.
